# 🏏 IPL Oracle: AI-Powered Player Guessing Engine

[cite_start]**IPL Oracle** is an intelligent, interactive guessing game inspired by "Akinator," specifically designed for the Indian Premier League (IPL) ecosystem[cite: 5]. [cite_start]Unlike traditional games that use static decision trees, IPL Oracle leverages **Generative AI** and **Probabilistic Reasoning** to identify any IPL player (past or present) through a sequence of dynamic, high-impact questions[cite: 4, 13].

---

## 🚀 Core Features

* [cite_start]**Dynamic Questioning:** No hardcoded logic or static if/else flows[cite: 30, 34]. [cite_start]The AI generates context-aware questions in real-time based on your previous answers[cite: 7, 33].
* [cite_start]**Information Maximization:** Every question is designed to maximize entropy reduction, narrowing down the pool of all IPL players from 2008 to the present[cite: 18, 25, 42].
* [cite_start]**Confidence-Based Logic:** The engine triggers a final guess only when it reaches a confidence threshold of **≥ 80%**[cite: 44, 59].
* [cite_start]**Adaptive Learning:** The system incorporates user feedback ("No, that wasn't my player") to improve future predictions and knowledge[cite: 48, 49, 50].
* [cite_start]**Efficiency:** Designed to identify the target player in a strict maximum of **8 questions**[cite: 46, 60].

* [cite_start]**Backend:** Powered by **Node.js**, handling the asynchronous AI engine loop and candidate probability updates[cite: 52].
* [cite_start]**AI Engine:** Integrated with the **Gemini API** for dynamic question generation and reasoning logic[cite: 89].
* [cite_start]**Database:** Utilizing **Google Sheets or BigQuery** as the foundational database for historical IPL player stats[cite: 93].

## 🧠 The Engine Loop

[cite_start]The system operates on a sophisticated AI-driven deduction loop[cite: 52]:
1.  [cite_start]**First Question:** AI asks a broad, high-impact question[cite: 53].
2.  [cite_start]**User Input:** User responds with *Yes, No, Maybe,* or *Don't Know*[cite: 54].
3.  [cite_start]**Probability Update:** The system updates candidate probabilities across the entire IPL player pool[cite: 55].
4.  [cite_start]**Optimal Selection:** AI selects the next question based on the updated pool to minimize steps[cite: 56].
5.  [cite_start]**Final Prediction:** Once confidence is high, the AI makes its guess: *"You're thinking of [Player Name], right?"*[cite: 65, 66].
